# UNO自動宣言装置

スマートフォンのインカメラで手札を認識し、残り1枚になったら自動でUNOを宣言するシステム。

---

## システム構成

```
web/        Webアプリ（カメラ認識・UNO演出・BLE通信）
firmware/   ESP32ファームウェア（LED + サーボ制御）
docs/       要件定義・タスク管理ドキュメント
```

---

## 装着方法

スマートフォンを**上下逆に**首から下げて使用する。インカメラが手札側を向くよう角度を調整する。
UNO表示は上下反転して描画されるため、観客からは正しく見える。

---

## モード

### 通常モード
- 手札が1枚になったことを検知すると音声を再生
- 画面中央に「UNO」を上下反転してシンプルに表示
- 画面タップで消去・次の検知へリセット

### スーパーUNOアピールモード
- 手札が1枚になったことを検知すると音声を再生
- 「UNO」が画面いっぱいにスタンプ演出で表示（上下反転）
- 背景がゆっくり色変化し、大量の「UNO」文字が流れる（ニコニコ動画風）
- 画面タップで消去・次の検知へリセット
- BLE経由でESP32へ通知 → LED点灯・サーボ動作

---

## カード認識アルゴリズム

Canvas API のみで実装（外部ライブラリ不使用）。

1. 200ms ごとにガイド枠内の映像フレームを取得
2. 各ピクセルを RGB→HSV 変換し、UNO固有の色相範囲（赤・青・緑・黄）かつ高彩度のピクセルを抽出
3. 白マスクの積分画像を構築し、近傍に白ピクセルがあるUNO色ピクセルのみをカード領域とみなす
4. 面積比で `none / single / multiple` を判定
5. `multiple → single` の遷移後、3フレーム連続で `single` が続いたらUNO宣言

## 動作環境

| コンポーネント | 要件 |
|---|---|
| Webアプリ | Chrome for Android / HTTPS必須 |
| BLEデバイス | M5Atom Lite（スーパーモードのみ） |
| サーボ | SG90（PWM制御）（スーパーモードのみ） |
| 電源 | 単3×4 または USB 5V（サーボ用外部電源） |

---

## セットアップ

### Webアプリ（Vercel）

1. [vercel.com](https://vercel.com) でリポジトリをインポート
2. Root Directory: `web` を指定
3. スマートフォンの Chrome でデプロイ先 URL にアクセス
4. カメラ使用許可を承認してモードを選択

### ローカル開発

```bash
cd web
npm install
npm run dev
```

デバッグ画面（閾値スライダー・カード状態の色枠表示）はモード選択画面の「デバッグモード」ボタン、または `/debug` で確認できる。

### ESP32ファームウェア（M5Atom Lite）

必要なライブラリ（Arduino IDE ライブラリマネージャーでインストール）

- FastLED by Daniel Garcia
- ESP32Servo by Kevin Harrington

手順

1. Arduino IDE で `firmware/uno_flag/uno_flag.ino` を開く
2. ボード: `M5Atom` を選択
3. サーボを配線し、外部電源を接続（GND共通）
4. 書き込み

---

## 制約事項

- Chrome for Android 専用（iOS Safari 非対応）
- HTTPS 環境が必須（getUserMedia / Web Bluetooth API の要件）
- 照明条件・カードの重なり方により認識精度が変動する（`/debug` ページで閾値調整可能）
- 閾値はデバッグ画面で設定した値が localStorage に保存され、本番アプリにも反映される
